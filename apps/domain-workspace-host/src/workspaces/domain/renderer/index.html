The domain workspace is ready.

This surface is the second workspace of the application. It lives beside the general-purpose ZCode workspace — never on top of it, never replacing it. Switching between the two environments slides horizontally and preserves the complete state of both. Domain-specific product surfaces will be built here in later milestones; this foundation carries none of them yet.

Independent workspace environment

About this workspace

The domain workspace is an ordinary Chromium surface owned by the PlayLiquid host layer. It runs from its own files under apps/domain-workspace-host/, in a dedicated, non-persistent session partition, sandboxed, with node integration disabled.

Provenance

Every file of this surface is new. The upstream ZCode tree at the fork baseline is untouched — machine-checked by scripts/verify-upstream-integrity.mjs.

additive only · zero upstream edits

State contract

Switching workspaces never resets either side: the upstream workbench keeps tasks, sessions, terminal, browser and composer state; this page keeps its route and view state.

no unmount · no reload · no reset

What comes next

Later milestones will build real domain product surfaces here. The foundation intentionally ships none of them.
